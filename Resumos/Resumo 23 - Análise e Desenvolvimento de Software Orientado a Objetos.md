Hoje iniciando as postagens com os resumos da cadeira de Modelagem do Sistema com a análise orientada a objetos, abordarei o Paradigma Orientado a Objetos (POO).

Basicamente, o POO é uma técnica que consiste em desenvolver os sistemas de software , utilizando modelos organizados a partir de conceitos do mundo real, como uma coleção de agentes interconectados chamados objetos, sendo cada um responsável por realizar tarefas específicas. As ações do sistema são realizadas a partir da interação desses objetos.

As principais características desse paradigma segundo Booch, Rumbaugh e Jacobson(2006) são:
🔩 Reusabilidade: É a capacidade de reuso de componentes na implementação, proporciona diminuição de custos e tempo de desenvolvimento.

👨‍👦 Extensibilidade: Se refere ao conceito de herança, onde partes do software teriam seu uso estendido a objetos herdeiros, desse modo, classes genéricas (pai) podem ser acrescidas de funções comuns a classes especializadas(filho).

🔐 Confiabilidade: Reforçada a partir da aplicação dos conceitos de encapsulamento das classes, que torna o acesso às estruturas de dados privado aos objetos.

🛠 Manutenibilidade: Referente à facilidade de possíveis correções, decorrentes de mudanças pontuais nos objetos.

# Administração da manutenção do software 🕵‍♂️ 🔨 
>[!Note]
>Resumo 34, Especialização em Eng. de Software por Bruno Rijo

Geralmente, tem-se um conceito de que um software é desenvolvido durante um tempo e depois entra em operação e fica eternamente disposto ao usuário, que não surgem bugs ou nenhuma alteração é realizada até o dia que seja preciso substituir esse software por uma mudança de SO ou de necessidade mesmo. Porém, a crescente exigência nos negócios torna incontável o número de intervenções nos sistemas durante o desenvolvimento e uso do mesmo.

Taentzer (2019) afirma que “a evolução é um fenômeno natural no ciclo de vida de sistemas de software de acordo com diversas razões para mudanças”.

Os elementos envolvidos no processo de manutenção de um software são as seguintes:

### Produtos de Manutenção 
Enquanto o produto é o software que foi entregue previamente, o produto atualizado, como já é esperado que seja, é a representação de uma versão acrescida de artefatos que podem ser: componentes em código, novas verificações e validações, novos designs, etc

### Atividades de Manutenção
Refere-se a habilidade técnica necessária para realização da manutenção ou melhorias implementadas.

### Processos Organizacionais de Manutenção
Trata-se do gerenciamento da manutenção, onde os gestores devem investir mais esforço e foco a fim de definir quais serão os procedimentos mais apropriados para cada situação como: guia de atividades, técnicas utilizadas, métodos de análise, garantias de qualidade, etc.

### Pessoal da Manutenção
A equipe responsável, propriamente dita.

São vários os tipos de manutenção que podem ser realizadas, vou listar brevemente as classificações e subclassificações dos mesmos.

Inicialmente, podemos ter manutenções de Correção e Evolução, que já são autoexplicativas. Segue as subclassificações de cada uma:
- **Correção Corretiva**: Necessária quando algum bug é identificado, na maioria das vezes pelo usuário.
- **Correção Preventiva**: Quando o time percebe proativamente potenciais falhas e erros, antes que cheguem ao usuário final.
- **Evolução Adaptativa**: Quando se faz necessária devido atualização de outros software ou sistema operacional que afetam diretamente o uso do mesmo.
- **Evolução Perfectiva**: Possui foco em melhoria de usabilidade, performance, necessidade de refatoração, e até mesmo para adicionar, alterar ou remover funcionalidades.

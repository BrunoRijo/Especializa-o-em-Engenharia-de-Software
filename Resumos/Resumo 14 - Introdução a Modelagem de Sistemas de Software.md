# Introdução a modelagem de sistemas de software 💻 🚀 
>[!NOTE]
>Resumo 14, Especialização em Eng. de Software por Bruno Rijo

A modelagem é uma das etapas do desenvolvimento que precede a implementação de um sistema de software, ela consiste no processo de transformar os requisitos em documentos que serão interpretados pelos profissionais envolvidos no processo.

Segundo Fabris e Perini (2014), a partir de perspectivas diferentes, é possível criar diversos modelos padronizados para representar o sistema que será implementado, considerando o ambiente que ele será utilizado após o processo de implantação.

Uma das melhores maneiras de representar os "roteiros" de desenvolvimento, a serem definidos na etapa de modelagem é através de diagramas UML, que é o padrão mundial para modelagem de sistemas adotado em praticamente todas as ferramentas CASE desse segmento. 

A principal vantagem de padronizar a modelagem de dados, é fazer com quem todos os profissionais de TI ao redor do mundo, são capazes de compreender a estruturação de um software, apesar do idioma, linguagem de programação ou demais contextos. Pois os elementos visuais que compõem os diagramas seguem modelos universais. Basta que o desenvolvedor saiba identificar o significado de cada elemento que compõe um diagrama UML.

Os modelos gráficos geralmente são utilizados de três formas distintas:
1. Para facilitar a visão geral do sistema, e o entendimento sobre o mesmo.
2. Para documentar o sistema.
3. Para descrever detalhadamente o sistema, afim de que o projeto seja uma base para a sua implementação.

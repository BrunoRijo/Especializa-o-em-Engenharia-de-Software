## Ferramentas CASE para etapa de modelagem de Banco de Dados 🗄️📋
>[!NOTE]
>Resumo 13, Especialização em Eng. de Software por Bruno Rijo

A etapa de modelagem de banco de dados é de extrema importância no desenvolvimento de software, é a primeira etapa e uma das mais importantes pois se trata de uma estrutura onde todos os dados serão armazenados para serem gerenciados e manipulados através do software.

A estruturação do banco de dados, ao contrário do que muitas pessoas pensam, deve ser implementada ANTES da etapa de codificação! Além de implementar o BD, é necessário fazer a estruturação através de modelos específicos, como o modelo entidade-relacionamento.

Hoje, eu apresento três ferramentas CASE criadas para auxiliar esse tipo de modelagem

➡ DB-Main

É uma ferramenta proprietária (paga) de modelagem que cria os processos existentes em um projeto de banco de dados, como: análise de requisitos, modelo entidade-relacionamento (conceitual, lógico e físico), normalização, integração e otimização de esquemas de dados
Além disso, permite a geração de códigos escritos em SQL a partir de modelos criados nele.

➡ DB Designer

É uma ferramenta gratuita, que permite modelar, criar e fazer manutenção de um sistema de banco de dados em um único ambiente. Ele permite a compatibilidade direta com SGBD, como MySQL, SQL Server, PostgreSQL, ORACLE e SQLite.
Além disso, também permite a geração de script SQL dos modelos criados  nele e possui uma grande e ativa comunidade de usuários  por ser de código aberto

➡ BrModelo

Criado em 2005, voltado para o ensino, o BrModelo é uma ferramenta de código aberto desenvolvida por um brasileiro , para modelagem de esquemas de banco de dados relacionais, incluindo as etapas conceitual, lógico e físico.
Com ênfase no ensino e aprendizagem de técnicas de modelagem baseadas no modelo entidade relacionamento. 
Possui uma interface simples e intuitiva, e é totalmente gratuita.
